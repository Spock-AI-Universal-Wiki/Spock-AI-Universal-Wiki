    spock_onboarding/fit_select.py¶

    *Recipe-driven GGUF shortlists for Bringup step 3 Acquire.

    Acquire used to auto-pick from a three-tier catalog keyed on one VRAM number. This module instead reads the host recipe — the same artefact Launch uses — and ranks candidates per role the way llmfit does, so the user chooses from models that actually fit the machine they are on.

    The Hub is preferred for candidates and the built-in catalog*
